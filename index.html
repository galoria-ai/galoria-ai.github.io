Supported images, review, and recovery

Galoria discovers JPG, JPEG, PNG, WEBP, GIF, BMP, TIFF, HEIC, and HEIF images. It combines filenames, folder context, metadata, dimensions, and optional local visual captions when available. Visual analysis is bounded and uncertain images can still need manual review. Before anything moves, you can inspect destinations and conflicts, then choose Move or Keep for each image. Applied moves are recorded in local history, and the latest organization operation can be undone with a valid license.

How Galoria works

  1. Select a folder on your computer.
  2. Galoria analyzes supported image files locally.
  3. Review proposed categories and destinations, then choose which images move.
  4. Apply only the changes you approve.

Frequently asked questions

Does Galoria upload my photos?

No. Galoria's organization workflow analyzes supported image files locally on your computer instead of uploading them to a cloud organizer.

Can I preview changes before images move?

Yes. Galoria shows each image with its proposed folder and lets you choose Move or Keep before applying changes.

Can I undo changes?

The app keeps a local history log and supports undo for the latest organization operation after changes are applied.

Does it require a subscription?

No. Galoria is offered as a one-time $14.99 purchase rather than a recurring subscription.

Which operating systems are supported?

Galoria supports Windows 10 and Windows 11.

What kinds of images can it organize?

Galoria is positioned for screenshots, camera photos, people shots, receipts, documents and scans, product images, wallpapers, memes, travel photos, food, pets, and design assets.

Does it work without internet?

Image analysis and organization run locally. Internet access is still needed to download and activate the app.

How do I install it?

Open Download for Windows on this page, complete checkout, and use the Galoria installer supplied through the official purchase flow. Start with a copied or noncritical image folder and review the proposed result before applying changes.

What happens if it does not work on my device?

Check the installation and troubleshooting pages, then contact support@computoraai.com with your Windows version, downloaded filename, and exact error message if the problem continues.
