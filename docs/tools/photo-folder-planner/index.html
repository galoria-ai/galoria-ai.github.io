How to use the preview safely

Screenshot, receipt, scan, and design words in names are hints, not proof of what an image shows. Camera-style names and ambiguous names stay in Review. Open each image yourself before moving it. Similar names may be edited versions; this tool does not detect duplicates. Keep a backup and test a few manual moves before reorganizing a large library.

A folder plan is useful when names are descriptive and you want a quick manual starting point. It cannot classify an image by what is visible in it. Galoria is a separate Windows 10/11 desktop organizer: it analyzes supported images locally, including bounded optional visual captions, and lets you review and change proposed destinations before approved physical moves. It does not delete photos or guarantee a correct category. Download and license activation require internet access.
